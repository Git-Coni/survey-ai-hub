## 🔄 API 호출 흐름 분석

### 1. 서버 시작 흐름
```

```

### 2. API 엔드포인트별 흐름

#### GET /api/surveys (설문 목록 조회)
```
클라이언트 요청
    ↓
server.ts (라우터 등록)
    ↓
routes/surveys.ts (router.get("/", ...))
    ↓
controllers/surveyController.ts (getSurveys)
    ↓
models/survey.ts (SURVEY_METADATA)
    ↓
JSON 응답 반환
```

코드 흐름:
```typescript
// 1. 라우터에서 컨트롤러 메서드 호출
router.get("/", surveyController.getSurveys.bind(surveyController));

// 2. 컨트롤러에서 메타데이터 조회
async getSurveys(req: Request, res: Response) {
  const surveys = Object.values(SURVEY_METADATA).map((metadata) => ({
    type: metadata.type,
    name: metadata.name,
    description: metadata.description,
    // ...
  }));
  res.json({ surveys });
}
```

```
    ↓
routes/surveys.ts (router.get("/:type", ...))

controllers/surveyController.ts (getSurveyMetadata)
```

#### GET /api/surveys/:type/questions (설문 질문 조회)
```
클라이언트 요청 (/api/surveys/teto-gender/questions?lang=ko)

    ↓
controllers/surveyController.ts (getSurveyQuestions)
```

현재 문제점: 실제로는 DB에서 조회해야 하지만 임시 데이터를 사용 중

## 🔧 권장 개선사항

### 1. 데이터베이스 연동 완성
```typescript
// controllers/surveyController.ts 수정
import { getDatabaseService } from "../utils/database";

export class SurveyController {
  private dbService: DatabaseService;

  constructor() {
    this.dbService = getDatabaseService();
  }

  async getSurveyQuestions(req: Request, res: Response) {
    const { type } = req.params;
    const { lang = "ko" } = req.query;
    
    // DB에서 설문 유형 조회
    const surveyType = await this.dbService.getSurveyType(type);
    if (!surveyType) {
      return res.status(404).json({ error: "Survey type not found" });
    }
    
    // DB에서 질문 조회
    const questions = await this.dbService.getSurveyQuestions(
      surveyType.id, 
      lang as string
    );
    
    res.json({ type, questions, metadata: surveyType });
  }
}
```

### 2. 표준 응답 형식 도입
```typescript
// utils/response.ts 생성
export interface ApiResponse<T> {
  success: boolean;
  data: T;
  message?: string;
  timestamp: string;
}

export function createResponse<T>(
  data: T, 
  success: boolean = true, 
  message?: string
): ApiResponse<T> {
  return {
    success,
    data,
    message,
    timestamp: new Date().toISOString(),
  };
}
```

```typescript
  const missing = required.filter(key => !process.env[key]);

    throw new Error(`Missing required environment variables: ${missing.join(', ')}`);
  }
}
```
